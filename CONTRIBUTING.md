# Contributing to YORDINDIA projects

This guide applies to every YORDINDIA repository that has no `CONTRIBUTING.md` of its own.

## Before you start

1. Read the repository `README.md` for setup and commands.
2. For a large change, open an issue first so that we can agree on the approach.

## Send a pull request

1. Fork the repository and create a branch from `main`.
2. Keep each pull request to one change.
3. Run the build, lint, and test commands from the README. CI must pass.
4. Open the pull request against `main` and fill in the template.

Pull requests are squash-merged. The pull request title becomes the commit title, so write it as a short imperative sentence, for example "Fix crash when the library is empty".

## Conduct

All contributors must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
