# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

- **GitHub:** open the repository's **Security** tab and select **Report a vulnerability**.
- **Email:** [saksham1991999@gmail.com](mailto:saksham1991999@gmail.com)

Include the affected repository, version or commit, steps to reproduce, and the impact.

We reply within 7 days and tell you when a fix is released.

## Supported versions

Only the latest release, or the latest commit on `main`, gets security fixes.
